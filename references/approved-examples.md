# 获认可的视觉基准：柯桥文章配图

用户于 2026-10-29 明确认可这一版，并要求作为以后文章与讲解类配图的默认风格。随 Skill 附带四张示例，路径为 assets/examples/keqiao/；官方角色识别原件仍在 assets/character/。外部媒体库保留原文章包。

- [中文封面](../assets/examples/keqiao/cover-zh.png)：掀开布料露出微缩织造车间；大标题、强材质、人物服务动作。
- [英文封面](../assets/examples/keqiao/cover-en.png)：同一视觉主题独立组织英文排字，适配海外渠道。
- [制造与交易](../assets/examples/keqiao/manufacturing-and-trading.png)：连续布料连接织机与色卡，九两参与连接关系，两个短标签。
- [把实力变成证据](../assets/examples/keqiao/proof-over-promises.png)：纤维、玻璃、水珠和放大镜的材质对照，一句大字点题。

调用时查看最接近本次用途的 1–2 张。学习立体材质、物理动作、空间关系、柔和光线和留白，不机械复制布料、放大镜、蓝橙配色或人物站位。其他行业用对应材料与业务物件重新组织。
